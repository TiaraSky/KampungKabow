# KampungKabow

## Tentang Project

KampungKabow merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan data dan informasi kampung. Aplikasi ini dibuat menggunakan PHP, HTML, CSS, dan JavaScript.

Project ini memiliki beberapa halaman utama seperti login, dashboard, data penduduk, master data, dan pengelolaan pengguna.

## Fitur Aplikasi

- Login pengguna.
- Dashboard.
- Pengelolaan data penduduk.
- Pengelolaan data pengguna.
- Halaman master data.
- Navigasi antarhalaman.
- Pengelolaan koneksi database.

## Teknologi yang Digunakan

- PHP
- HTML
- CSS
- JavaScript
- Database (sesuai konfigurasi aplikasi)

## Cara Menjalankan Project

1. Clone atau download repository ini.
2. Simpan folder project di direktori web server lokal.
3. Jalankan Apache melalui XAMPP.
4. Sesuaikan konfigurasi database pada file koneksi.php.
5. Pastikan database yang dibutuhkan sudah tersedia.
6. Buka aplikasi melalui browser menggunakan localhost.
